# TraderLock Server Docs

Start here when working in `trader-lock-server`:

- `architecture/current-system-design.md` is the current architecture guide for agents and contributors.
- `architecture/auth-and-users.md` documents the authentication and user identity rules.
- `architecture/shared-layer-taxonomy.md` explains what belongs in `shared` versus a module.
- `architecture/database-first-slice.md` is historical context for the first persistence slice. Prefer the current system design doc when the two differ.
- `dev/local-infrastructure.md` explains local PostgreSQL and test infrastructure.
